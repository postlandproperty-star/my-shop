# SheetLab — คู่มือผลิตชีท (house style ของบริษัท)

ทุกเล่ม: PDF A4 อธิบายภาษาไทย เนื้อหาอังกฤษ สำหรับคนไทยเตรียมสอบ TOEIC และภาษาอังกฤษใช้งาน
แบรนด์คือ **SheetLab** เท่านั้น ห้ามมีคำว่า academy_resources หรือชื่อร้านอื่นที่ใดในเล่ม

## เนื้อหา
- เขียนใหม่ทั้งหมด ห้ามคัดลอกหรือดัดแปลงข้อสอบจริง หนังสือ เว็บไซต์ เนื้อเพลง ตัวละคร โลโก้
- โครง: วิธีใช้ → สารบัญ → บท (ตามใบสั่ง) → แบบฝึกหัดท้ายบท ≥2 รูปแบบ ง่ายไปยาก → เฉลยละเอียดท้ายเล่ม ทุกข้อมีคำอธิบายไทย
- ทุกบทมีกล่อง "คนไทยพลาดบ่อย" (✗/✓) และ "เทคนิค"
- ภาษาไทยมาตรฐาน ไม่ใส่ ค่ะ/ครับ ในเนื้อหา ป้าย (UK)/(US)/(ภาษาพูด) เมื่อจำเป็น
- ใช้ subagent เขียนบทขนานเป็น JSON แล้วใช้ subagent อีกชุดตรวจเฉลยทุกข้อ (ทำเองก่อนแล้วเทียบ) แก้ข้อกำกวม
- จำนวนหน้าตามใบสั่ง ± 20% ถ้าเนื้อหาต้องการมากกว่านั้นให้ผลิตตามเนื้อหาแล้วรายงานหน้าจริง

## เครื่องมือ (คอนเทนเนอร์คลาวด์)
- ฟอนต์: `npm i @fontsource/kanit @fontsource/noto-sans-thai @fontsource/prompt` โหลด woff2 ผ่าน file:// @font-face (ดู build_reference.py)
- เรนเดอร์: Playwright Chromium `page.pdf(format A4, print_background, displayHeaderFooter)` ถ้าไม่มี Playwright ให้ `pip install playwright && python -m playwright install chromium` (หรือ `npx playwright install chromium --with-deps`)
- ตรวจ: ฟอนต์ฝังครบ (pdffonts หรือ pypdf) ไม่มีตัวแทนค้าง (@@, TODO, [ใส่…]) สารบัญตรง เฉลยตรง ย่อขนาดด้วย qpdf หรือ pypdf ถ้ามี
- build_reference.py คือสคริปต์ที่ใช้ผลิต "TOEIC GRAMMAR 15 จุด" ให้ก๊อป CSS, fontface(), หัว/ท้ายกระดาษ, ปก และ two-pass TOC มาปรับเป็นสี/แบรนด์ SheetLab

## ส่งมอบ (ผ่าน API เท่านั้น ไม่มีการเขียนลงเครื่องใคร)
1. รับใบสั่ง GET /api/content?action=factory&status=queued
2. จอง POST action=factory_claim {id}
3. ขอที่เก็บไฟล์ POST action=factory_uploadurl {id, filename} → {upload_url, file_url}
4. อัปโหลด PUT upload_url (Content-Type: application/pdf, body = ไฟล์)
5. ปิดงาน POST action=factory_done {id, file_url, pages, size, summary}
ไฟล์ทุกไฟล์อยู่บนคลาวด์ของบริษัท (Supabase Storage ของโปรเจกต์ SheetLab) เท่านั้น
