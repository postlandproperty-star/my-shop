# Shopee Boost (ดันสินค้าอัตโนมัติบน Mac)
กด "โปรโมทตอนนี้" ใน Seller Centre ให้เองทุก 4 ชม. ใช้ Google Chrome ในเครื่อง ไม่ต้องใช้ API ไม่ต้องลงแอปจาก App Store / Play Store

## ติดตั้งครั้งแรก (ทำครั้งเดียว ~10 นาที)
1. ต้องมี **Google Chrome** และ **Node.js** (ตัวติดตั้ง LTS จาก https://nodejs.org)
2. เปิดแอป Terminal แล้วเข้าโฟลเดอร์นี้ เช่น `cd ~/my-shop/tools/shopee-boost` แล้วรัน `npm install`
3. แก้ `products.txt` ให้เป็นชื่อสินค้า (ท่อนแรกของชื่อพอ) ที่อยากดัน สูงสุด 5 ชิ้น
4. `node boost.mjs --login` → Chrome เปิดขึ้น ล็อกอินร้าน (กรอก OTP ถ้ามี) เห็นหน้าสินค้าของฉันแล้วปิดหน้าต่าง
5. `node boost.mjs --dry` → ลองหาเมนูทุกชิ้นแต่ยังไม่กด ทุกบรรทัดควรขึ้น "เจอเมนูโปรโมทตอนนี้"
6. `bash install.sh` → ตั้งให้รันเองทุก 4 ชม. 5 นาที (รอบแรกรันทันที)

## ใช้งานประจำ
- ผลแต่ละรอบ: `~/.shopee-boost/log.txt` · ภาพหน้าจอรอบล่าสุด: `~/.shopee-boost/shots/`
- มีปัญหาจะมีแจ้งเตือนมุมขวาบนของ Mac เช่น "หลุดล็อกอิน" → รันข้อ 4 ใหม่
- Mac ต้องไม่หลับ: ตั้งค่าระบบ → แบตเตอรี่/พลังงาน → เปิด "ป้องกันไม่ให้พักเครื่องอัตโนมัติเมื่อจอปิด" ตอนเสียบสายชาร์จ (จอดับได้ ล็อกจอได้ แต่อย่าปิดฝา MacBook)
- ทุกรอบจะมีหน้าต่าง Chrome เด้งขึ้นมาราว 30 วินาทีแล้วปิดเอง ไม่ต้องทำอะไร
- เปลี่ยนสินค้า: แก้ `products.txt` ได้เลย รอบถัดไปใช้ชื่อใหม่ · เลิกใช้: `bash install.sh off`
