## จังหวะ
- รอบ 2569 เปิดรับสมัคร ม.ค. คนค้นหาเยอะช่วง ธ.ค.–ก.พ. และก่อนวันสอบ จึงควรขึ้นเว็บตั้งแต่ ต.ค.–พ.ย. ให้ Google เก็บทัน
- หลังขึ้นเว็บ: ส่ง sitemap ใน Google Search Console (`https://sheetlabth.com/sitemap.xml` มีหน้า /gov ครบ)

## ชุดถัดไป (เรียงตามความสำคัญ)
1. อังกฤษ: Vocabulary in context, คำเชื่อม (however/therefore), ข้อสอบบทสนทนาชุด 2
2. คิดวิเคราะห์: อนุกรมตัวอักษร, ตาราง/กราฟ, อุปมาอุปไมยภาษาไทย, การเรียงประโยคชุด 2
3. สนามอื่น: ภาษาอังกฤษสอบท้องถิ่น, ภาษาอังกฤษครูผู้ช่วย (เพิ่มเป็นบทความแยกเมื่อมีข้อมูลรูปแบบสอบที่ยืนยันได้)
4. ข้าราชการที่ดี: เฉพาะหลักการที่มั่นคง ตรวจกับตัวบทที่สำนักงานคณะกรรมการกฤษฎีกาก่อนทุกครั้ง

## วิธีเพิ่มเรื่องใหม่
1. เขียนไฟล์ JSON ในโฟลเดอร์นี้ (บทความ: slug, subject eng|think|law, title, desc, quiz_slug, body · ข้อสอบ: `<slug>.quiz.json` มี questions)
2. `node tools/content/gov-seo/build.mjs` → ตรวจรูปแบบ ลิงก์ต้องอยู่ในโซน แล้วสร้าง `lib/govContent.js`
3. ตรวจเฉลยทุกข้อซ้ำโดยคนอื่น → `npm test` → PR → Merge

## กติกาเนื้อหา
- ห้ามข้อมูลที่เปลี่ยนตามรอบสอบ (วันสอบ ค่าสมัคร เกณฑ์ จำนวนข้อ) ให้ลิงก์ไป `/gov/kp-phak-kor` แทน
- ห้ามอ้างว่าเป็นข้อสอบจริงหรือข้อสอบเก่า ห้ามสัญญาคะแนน
- ลิงก์ภายในเฉพาะ `/gov...` (build.mjs ไม่ยอมสร้างถ้ามีลิงก์ออกนอกโซน)

## วัดผล (ทุก 2 สัปดาห์)
- Search Console: คำค้นที่พาเข้า /gov/learn/* อันดับเฉลี่ย คลิก
- สถิติร้าน: คนเข้า /gov/* → คลิกข้อสอบ → คลิกชีท
- บทความไหนมีคนเข้าแต่ไม่มีคนกดข้อสอบ = ปรับปุ่มชวนทำข้อสอบ
